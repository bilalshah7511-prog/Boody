# Boody — Checkout Skin Demo

PayPhi-style checkout drawer skin for [Boody](https://boody.com) (Outdoor Voices pattern).

## Font

**Sofia Pro Regular only** (`public/fonts/sofiapro-regular.otf`). No other typefaces.

## Run

```bash
npm install
npm run dev
```

## Brand notes

- Accent / banner: Boody grey `#54565A`
- Product: Full Briefs (Black / Shell / Light Grey Marl / Dune) — $18
- Promo: `BOODY10`, `SAVE20`, `FREESHIP`
- Free shipping: `$60+`
